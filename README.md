# 粉色小心愿 · 日系可爱女孩换装版

轻轻清理，带回一份小美味，陪栗色双辫的小女孩实现她的粉色小心愿。

**最新试玩：[https://pore-master-clinic-latest.sunshinywood.chatgpt.site/](https://pore-master-clinic-latest.sunshinywood.chatgpt.site/)**

试玩入口已公开，可直接在手机或电脑浏览器中打开。

角色以用户确认的日系卡哇伊概念图为唯一视觉基线：白皙肤色、蜂蜜棕大眼睛、栗色双辫、褪色破旧的蓝灰布裙。默认人物直接显示批准原图中的完整人物，使用无损 WebP 保留原始 RGB 像素；不重新绘制脸、头发、破洞或缝补细节。三套解锁裙装、两种额外发型制作成完整的 4 × 3 组合画稿，避免衣领和发辫的拼接缝，换装时继续锁定原画面容。发饰、妆容、鞋和首饰继续支持十个部位独立搭配，首页、衣橱和结算使用同一个人物渲染器。

原生 HTML、CSS、Canvas 2D 与 Web Audio API 实现。角色画稿保存在 `assets/character/` 的十五张无损 WebP 中，和游戏代码一起提供；没有第三方图片、字体、音频或运行时服务依赖。离线运行时保留 `index.html`、`favicon.svg` 和 `assets/` 的相对目录结构。

## 现在怎么玩

1. 首页先见到穿着破旧蓝灰布裙、扎栗色双辫的小女孩，点击“开始冒险”。
2. 按提示热敷、清理、收集并擦净，最后完成舒缓冰膜，进入下一关。
3. 部分痘痘里藏着食物或稀有心愿，取出时会从原洞口由小变大飞出来。完成这一关后正式收进收藏；稀有物品会显示“你的运气超棒！”。
4. 从首页、底部“衣橱”或过关页进入收藏。在“心愿册”穿戴与摆放，在“美食篮”请女孩吃东西。

护理界面顶部只显示当前关卡，工具和操作提示留在操作区。游戏不展示错误率、误操作次数、护理评分或评级；随机礼物与评分无关。底部建议按钮、长提示和教学显隐均保留固定空间，不再缩放画布或打断按住操作。

发现物品时，顶部用紧凑提示条显示名称，约 2.8 秒后自动收起。可以直接上滑关闭，也可以点右侧 ×；横向拖动、轻碰或系统取消会回到原位。短时间出现几份礼物会合并显示，打开衣橱、回到主页或离开页面时会收起。关闭提示不影响发现记录，仍在过关后正式带回家。键盘可聚焦关闭按钮并按 Esc；聚焦期间不会自动消失。

## 关卡与礼物

前两关是轻松入门：第 1 关只有 3 处黑头，第 2 关只有 4 处黑头。之后在鼻翼与脸颊、鼻尖、下巴、额头和嘴巴周围随机换部位，相邻完成的关卡不会重复部位。不同部位有独立的皮肤轮廓，额头可见边缘发际与眉缘，唇周可见裁切粉唇，下巴有圆润下颌；护理目标避开这些边缘特征。

第 3 关为 6–8 处，之后通常为 8–12 处；连续完成 2–3 局多目标关卡后，穿插一局只有 3–4 处的轻松关卡。每局重新决定黑头、白头和深层目标的数量，相邻局总数也有变化。下巴明显偏向黑头，可以整局只有黑头；白头与需要破口的深层目标都不再每局必有。纯黑头局也不会在共享洞口里暗藏白头。部位、数量、变体与轻松局节奏都会保存，刷新和打开菜单不会重抽或推进。

奖励不按固定关卡周期发放，界面不预告哪一关会出现什么。每个新关卡只抽取一次，结果绑定具体痘痘并保存，刷新不会重抽。前两关只有食品奖励；普通关卡第 3–5 关永久物品概率为 8%，第 6–10 关为 13%，之后为 18%；少目标轻松局为同等级普通局的两倍，仍每局最多一件。永久物品从未拥有的装扮和心愿中统一抽取，增加新品类不会额外提高整局掉率。

目前有 20 件装扮，覆盖原来的十个装扮部位，并加入白雪公主的王冠和水晶鞋。所有未拥有的装扮均展示预览并统一标记“暂未获得”，美白面膜、蓝色公主裙、白雪公主的王冠和水晶鞋排在最前。新玩家的女孩只穿基础补丁裙，预览不会自动穿到身上。获得后才能使用；面膜、妆容、发型及衣服改变相应人物图层。

心愿册另外展示奶糖猫猫、布丁狗狗、蝴蝶结梳妆台、梦幻马车、酷炫宝马车、亮闪闪包包、云朵兔兔和星光音乐盒。这 8 件同属稀有永久池，收集后可以摆在女孩身边。宠物、房间摆件、出行、包包、玩偶五个位置互不干扰，也不覆盖原有衣服；再次选择可以收起，收藏仍保留。

## 换装镜与互动反馈

衣橱固定显示人物和操作反馈，只有物品列表滚动；手机上翻到最下方也能看到换装结果。佩戴发饰、美瞳、口红、手链、项链或鞋履时，会自动显示对应部位的近景；“全身”和“看脸”可随时切换。再点当前穿戴的物品即可取下，只恢复该部位，其余搭配保留。

人物图片准备好后才显示换装完成和回应动作，加载期间保留上一张完整画面；快速连续选择时，只显示最后一次选择。图片加载失败时可点击“重新加载装扮”，不会清空已经选好的搭配。

宠物、玩偶和其他心愿摆件显示在人物白底之上，摆放与收起都有物品名称反馈。女孩有轻微待机摆动、换裙后的开心摇摆、佩饰回应、投喂后的小跳和爱心；点一下女孩可以打招呼。系统设置减少动态效果时，会保留文字和装扮结果并停用这些动画。

## 美食与饥饿

食品更常见：第一关会藏一份，之后普通局 86% 概率藏食品，其中 24% 会有两种；轻松局提高为 96%，其中 40% 会有两种。同局不重复，跨局可累积。8 种美食包括草莓小蛋糕、蜂蜜吐司、爱心蛋包饭、水果杯、布丁、蘑菇汤、饭团和热可可。

饥饿程度在主页和收藏页显示，范围 0–100，初始为 38，每完成一局增加 12。停留、离线或打开菜单不会增加，饥饿不会阻挡闯关。点击“请她吃”会消费一份，减少对应饥饿值，并显示“谢谢你的款待！”。吃饱时不会继续消耗食品；最后一份用完后不再可喂食，卡片恢复“暂未获得”。食品与心愿摆件的未获标签也与服装一致，库存和饥饿通过同一份存档保存。

饥饿达到 80% 且篮子里有食物时，女孩会在游玩空隙主动讨吃；100% 时突出满饥饿和可怜巴巴的请求。弹窗显示当前装扮的女孩、饥饿百分比和进度条，“喂她吃一点”直接打开美食篮，再由玩家选择食物；“等一下”、关闭按钮、Esc 或点遮罩均可继续游戏。提醒等真实鼠标、触摸或键盘护理动作全部松开后再出现，不覆盖奖励、结算和其他菜单。同一局最多出现一次，并保存冷却；关闭或成功喂食后至少安静五分钟。提醒本身不扣食物、不改变关卡奖励。

## 清理画面与操作

黑头身体为光滑的浅色，仅顶端呈黑色，没有横向条纹。从孔口竖直向上挤出，普通款保留轻微、稳定的倾斜，巨型款更接近笔直的粗柱，不再盘卷或弯成香蕉。新生成的普通孔半径为 14–18 CSS 像素，基准挤出长度为 34–46 像素；单根身体直径至少 7 像素，多根组合每根至少约 5.9 像素，旧存档里的细小款也有可见粗度下限。巨型款在普通基准上约为 2.2 倍长度、2.1 倍粗度；短屏会限制长度以保留完整可见轮廓。皮肤残留、飞行物和托盘同步使用柱状外观。

黑头更集中地形成一小片，相邻孔口保持间隔。用轻柔挤压选中其中一处并向内轻推，会同时带动附近最多四处普通黑头；鼠标、单指、双指和键盘使用同一规则。一处先排空时继续处理同组剩余黑头，整组完成后自动停手；每个孔仍独立保存进度、收集物和礼物，不会重复结算。白头、深层目标和共享双内容洞口保留单独处理方式。选中孔口中心也可以开始；密集区域从远处按下可能选中更靠近落点的其他目标。

取出后的洞口使用浅肤色或浅粉色，黑头不会出血；部分白头可以出现少量血珠，并非每个洞口都有血。双洞相连的黑头共用一个目标和一根提取物，处理后两个洞口一起清空。

共享洞口有两种内容顺序：黑头与白头一起露出、一起取出；或先取出黑头，再从原洞口继续挤出白头。洞口位置保持固定，顺序模式只有第二种内容也清理完成才算完成这一处。挤压不显示手指模型，保留皮肤的挤压反馈。

第 3 关起增加同孔逐颗揭晓的黑头、白头：表面只露出当前一颗，完全挤出或夹走后，这颗飞入收集盘，原洞口才露出下一颗。每次需要松手再操作，长按、键盘重复和保留旧触点都不会自动清空后续内容；新露出的颗粒已经破口，可再挤或夹取。常规多目标局白头、黑头逐颗孔各最多三处，白头优先，黑头较少的混合局也会安排逐颗惊喜，并保留其他黑头形态；第 3 关每类最多两处。多数藏两颗，部分藏三颗或四颗，少目标局只放一处两颗，前两关仍为普通入门。数量在生成时固定并随进度保存，界面不提前透露总颗数。每颗独立收集、计分，末颗完成才揭示该孔礼物并允许收尾；中途刷新仍接着当前颗。原有黑头后接白头的顺序孔也需要新的操作。

同坑 2–4 根黑头仍与逐颗孔混合出现：第 3 关起，未分配逐颗变体的独立黑头孔约四分之三为多根，长度可一致，也可错落不同。未挤出时，多根组合与同规格的普通黑头使用相同的单个黑头口，操作提示和键盘描述也不提前透露根数；挤出后才揭晓多根。第 4 关起约一半独立黑头孔为明显更长、更粗的巨型款，每局最多三处；仍有单根巨型和巨型组合。粗黑头和大块白头清理后均会留下浅粉肤色凹洞，冰膜再将其舒缓收拢。变体的长度和尺寸随护理点、残留、飞行与收集账本保存，按一处目标与一份组合收集物结算。渲染会限制在手机画布内，夹取任一外侧尖端仍保持原洞口位置。

热敷速度比此前约提高一倍，减少等待。皮肤底色也与整体粉色主题协调，保留明暗和微距触感。

细胞夹夹住目标后，会显示更大的拔出特写，同时保留洞口、整根黑头和实际咬合的夹口。取景预留完整拔出所需的空间，多根和巨型黑头会一起纳入画面；拖动时特写窗保持位置，进度直接显示在窗内。夹口跟随被夹住的真实顶端，完整拔出后短暂停留，显示根部脱离洞口的最后一下，再收起特写；飞往收集盘的动画从特写窗后方经过，不遮挡拔出结果。小屏会按可用画布调整窗口，横屏使用更宽的横向特写来容纳长黑头，粉刺针仍使用原来的精细瞄准放大镜。

**键盘**：用 `Tab` 聚焦护理画布，方向键选择目标，数字键换工具，按住 `空格` 或 `Enter` 操作，松开停止。粉刺针在松开时执行；`Esc`、失焦或切到后台会取消当前动作。

**鼠标与触屏**：根据目标状态跟随工具建议。拖动保持缓慢，触摸被系统取消、旋转屏幕或切换页面时会安全停手，回来后重新按住即可继续。工具区、衣橱与弹窗支持手机竖屏和横屏。

游戏中的皮肤与处理反馈仅为虚构玩法表现。

## 沉浸音效

热喷使用持续、轻柔的气流声，松手时渐弱；挤压、拔出、擦拭和落盘有不同的细小反馈。礼物出现时有清亮提示音，换衣服、佩戴配饰和使用护肤品也有各自的声音。支持的浏览器会加入轻微左右声像，全部通过 Web Audio 合成，不下载外部音频。

声音在玩家操作后才开始，底部喇叭按钮可以一键关闭并保存偏好。切到后台、失去焦点或交给另一页面时会停止；衣橱中的操作音与护理操作音分别管理，不会因为换装而重放此前暂停的游戏声音。

## 进度、换装与保存

进度自动保存在当前浏览器。关卡、当前护理、已发现的礼物、服装、心愿摆件、食品库存、饥饿和当前穿搭使用同一份 `PROFILE` 存档写入；刷新后可以接着玩。旧存档保留已有服饰与搭配，新字段补默认值，不清空既有收藏。

- **保存异常**：未写入成功时会持续显示提示。保持页面打开，存储恢复后点击“重试保存”；提示消失后再离开。无法读取的整份存档会保留原内容，不会直接覆盖。
- **多个页面接续**：同一浏览器中一次只在一个页面继续。第二页先暂停，点击“在这里继续”后接续最新存档；旧页停止操作，避免旧进度覆盖新进度。等待时可以取消。
- **另一页已有较新进度**：先确认接续提示，再决定是否使用已保存进度；这会放弃本页尚未保存的操作。
- **浏览器范围**：存档属于当前浏览器与网站来源，不会自动跨设备同步；本地文件、本地服务与线上站点也不共用存档。

## 本地运行

下载或克隆仓库后，直接在现代浏览器中打开 `index.html`。也可以在仓库目录运行：

```bash
python3 -m http.server 8080
```

随后访问 [http://localhost:8080](http://localhost:8080)。

## 构建与发布

```bash
npm run build
```

`scripts/build-static.cjs` 只使用 Node.js 标准库，无需先安装开发依赖。它先核对静态文件是否完整，再清理仓库自己的 `dist` 目录，复制 `index.html`、`favicon.svg`、十二张人物组合 WebP 和三张同画风鞋履 WebP；原始 PNG、测试、文档和 QA 页面不会进入产物。人物选择当前搭配对应的画稿，所有素材均使用本地固定白名单路径。

当前试玩链接通过 Sites 托管，发布静态产物 `dist`。其他静态托管平台也可直接使用同一产物。GitHub 提交、Actions 检查与线上部署是不同步骤；发布后应单独确认公开站点对应的提交，源码更新本身不代表线上已经更新。
