# 🏥 妙手净肤馆 (Pore Master Clinic)

基于原生 **HTML5 Canvas + CSS3 + JavaScript + Web Audio API** 开发的单文件高拟真微距清痘护理解压小游戏。零外部图片与音频依赖，双击 `index.html` 或部署至 GitHub Pages 即可在手机触屏与桌面端流畅运行。

## ✨ 核心特性

### 1. 真实面部解剖微距与物理形变
- **三大面部微距分区**：鼻翼沟与内侧脸颊、鼻头重度皮脂 T 区、下巴与唇周三角区；T 区粗大漏斗毛孔含天然皮脂丝，外侧脸颊细毛孔带细微毫毛。
- **无缝像素级夹挤网格变形**：双指捏合（或鼠标向内推挤）时，实时对挤压区皮肤纹理进行非线性切片压缩隆起，配合真实双拇指指甲甲床受压泛白细节。
- **双画风实时切换**：支持一键切换「🔬 写实微距肌」与「🍑 柔和奶油肌」。

### 2. 完全对齐现实生理的三类瑕疵机制
- **黑头粉刺（开放性脂栓）**：平嵌于粗大皮脂毛孔中，平时不红不肿、正常拔出只留干净的扩张空毛孔洞且不流血；顶端为固定长度深褐氧化帽，后段为乳黄半透明固态脂栓，中途松手会真实悬停在毛孔口半截。
- **白头粉刺（浅表熟痘）**：一挤破口先高速喷射稀脓并涌出奶黄脓珠，继续轻挤排出底部的「白米粒固态脂芯」，见到清亮组织液渗出即代表彻底排空。
- **红肿深层大痘（结节囊肿）**：未破口硬挤会导致皮下淤血红肿；需先用粉刺针挑破偏心浅黄脓尖，再放宽指距顺着椭圆长轴从底座往中间兜底推挤，直至蹦出深层固态脓栓核并渗出暗红静脉血珠。

### 3. 五步沉浸式护肤 SOP 与精工器械
1. **♨️ 热喷软化**：手持纳米热喷枪喷洒草本雾气，在皮肤表面真实凝结微水珠并舒张毛孔，降低拔栓阻力与顾客痛感。
2. **📍 粉刺针**：按住自动在触点上方开启 **2.2X 偏振光学微距瞄准镜**（解决手指遮挡），对准脓尖松手即可微创破口。
3. **🤏 手指挤压**：支持移动端真双指捏合与 PC 端鼠标防翻转对称推挤。
4. **🥢 超尖细胞夹**：借助 2.2X 放大镜咬合冒头黑头匀速外拉（毛孔唇缘随粘连力真实弹性牵拉，拉太快会夹断黑头帽），连根拔出后沿抛物线落入右上角不锈钢弯盘，点击弯盘可打开 **25X 超微距战利品检视窗**。
5. **🧼 消毒棉签 & 🧊 手刷冰感冻膜**：棉签擦拭实时染上脓渍/脂渍/血渍（再点一次可换新棉签）；全脸净空后可用硅胶刷涂抹微气泡冰感积雪草冻膜收缩毛孔，并在结算页左右拖动分割线对比 **「护理前 Before vs 护理后 After」**。

## 🚀 快速运行与部署

### 本地运行
直接用任意现代浏览器打开 `index.html`，或启动静态服务以便手机局域网扫码体验：
```bash
python3 -m http.server 8080
```

### GitHub Pages 在线预览
推送至 `main` 分支后，在仓库 **Settings -> Pages -> Build and deployment** 中选择 `Deploy from a branch`（`main` / `/root`），即可获得永久手机端全屏试玩链接。

## 🔧 物理参数调优
所有核心物理与数值平衡参数均集中在 `index.html` 顶部的 `CONFIG` 常量对象中（包含皮肤弹性阻尼、切片网格数、三类瑕疵阈值与拔栓断根速度上限等），可直接按需微调。
