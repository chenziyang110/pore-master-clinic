# 妙手净肤馆 · Pore Master Clinic

一间小小的净肤馆。放慢节奏，体验热敷、清理与舒缓护理的微距解压小游戏。

原生 HTML、CSS、Canvas 2D 与 Web Audio API 实现，全部内容都在 `index.html` 内。没有外部图片、字体、音频或运行时依赖，可直接离线打开。

## 画面与体验

- **护理工作台**：暖白、鼠尾草绿与细线器械图标；桌面端分开呈现护理记录与操作区，手机端采用紧凑的纵向布局。
- **两种肌理**：自然与柔和模式均由 Canvas 实时绘制；鼻翼、鼻头、下巴具有不同的表面起伏、毛孔分布和细微纹理。
- **细致反馈**：热敷凝露、局部放大镜、双指挤压、夹取进度与速度提示、残留擦拭，以及收集盘检视。镜面边缘保持准星与实际触点一致。
- **护理引导**：热敷、清理、舒缓三个阶段，实时软化与冰膜覆盖计数；根据当前目标状态提供可点击的下一工具建议。
- **完整护理流程**：五位顾客、器械升级、冰膜收尾、可拖动的护理前后对比、本地进度存档。
- **键盘与触屏**：工具快捷键、可见焦点、弹窗顶部关闭与焦点管理、Esc 关闭普通弹窗，以及系统取消触摸时的安全释放；手机竖屏与横屏分别布局。

游戏中的肤质、刺激度和处理反馈是玩法表现。

## 开始游玩

下载或克隆仓库后，直接在现代浏览器中打开 `index.html`。

也可以启动本地静态服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

| 工具 | 桌面快捷键 | 操作 |
| --- | --- | --- |
| 热喷 | `1` | 按住并缓慢扫过皮肤，先进行热敷 |
| 粉刺针 | `2` | 按住查看放大镜，对准深层痘的浅色尖端，松开破口 |
| 轻柔挤压 | `3` | 在瑕疵旁按住并向中心推；触屏也支持双指捏合 |
| 细胞夹 | `4` | 夹住已露头的黑头，缓慢向外拖动 |
| 清洁棉签 | `5` | 拖动擦净残留；再次选择可更换棉签 |

清理全部区域后，可以亲手涂抹冰膜，也可以选择一键敷膜，随后查看护理记录。顶部接诊台可切换顾客并升级器械；收入、器械和最高分保存在当前浏览器的 `localStorage` 中。

在接诊台点击标有“护理中 · 继续”的顾客，会回到当前进度。已有进度时，重新开始需要确认。结算对比图支持拖动，也可聚焦后用方向键调整分割线，`Home` / `End` 移到两端；下一次护理的数量可在“下一次护理设置”中选择。

## GitHub Pages

如果需要公开试玩，可在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，使用 `main` 分支和 `/ (root)` 目录。仅推送源码不会自动启用 Pages。

## 开发

无需构建。编辑 `index.html` 并刷新浏览器即可。

- `CONFIG`：玩法物理和数值参数。
- `CLIENTS` / `UPGRADES`：顾客内容与器械配置。
- `renderSkinTexture()`：基础皮肤、面部区域、毛孔和毫毛。
- `renderRealBlackhead()` / `renderRealWhitehead()` / `renderRealCyst()`：三类清理目标的外观。
- `bindCanvasInteractions()`：鼠标、触控与对比图操作。
- 页面顶部 `<style>`：颜色、排版、响应式布局与交互状态。

`push-to-github.sh` 只推送当前已提交分支，不强制覆盖远端，也不会自动暂存工作区文件。首次使用前需要在本机完成 GitHub 认证。
