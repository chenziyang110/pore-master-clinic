# 漫画角色视觉基线

这套原创角色是本项目当前唯一的人物视觉基线，采用蓝黑发、蓝紫眼、日系漫画线稿与分块上色。角色从空白生成，没有沿用此前的人物脸型、发型、身体路径或相关参考。

## 画稿与层

所有画稿使用 1086 × 1448 RGBA 坐标系。部署使用无损 WebP，转换前后 RGBA 像素完全一致。

- `manga-base.webp`：默认补丁裙、肩发与棕鞋。
- `manga-dress-sky.webp`：蓝色公主裙。
- `manga-dress-peach.webp`：蜜桃花边裙。
- `manga-dress-lilac.webp`：紫藤花裙。
- `manga-hair-bob.webp`：短波波头。
- `manga-hair-twintails.webp`：短双马尾。

`girlIllustration()` 将头部、服装、妆容和佩戴物组合为一个可访问的 SVG。衣服与头部使用独立区域，避免换衣时更换脸部，或换发时残留另一种头发。十个存档槽位和物品 ID 不变。

## 生成说明

使用内置 image_gen 生成基础立绘，后续五张画稿均以新基础立绘作为唯一编辑输入。基础要求：全新原创漫画女孩，蓝黑肩发、蓝紫大眼、正面稳定纸娃娃站姿，粉色补丁背带裙与奶油白短袖衬衫，白袜和棕鞋，细线稿、赛璐璐阴影、真实透明背景；无文字、道具和场景。

服装编辑只改变服装，保留脸、发型、站姿与手脚；发型编辑只改变头发，发尾保持在衣领以上。每个变体保留原画幅和坐标。图像生成并不保证逐像素锁定，因此运行时统一组合选定头像和服装区域。

## 后续美术修改

以本目录的新画稿作为参考。人物形象和服装/发型预览应同步更新；修改资产名时同时修改静态构建清单。原始 PNG 不进入发布包。发布前应检查默认、三套裙装、两种发型及十槽位全套搭配。
